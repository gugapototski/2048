Versao customizada do jogo 2048, com ajustes de interface, modos de jogo e ranking de melhores tempos.

## Destaques

- Jogo web estatico, sem backend.
- Ranking local de melhores tempos usando `localStorage`.
- Suporte a diferentes configuracoes de dificuldade.
- Codigo organizado na raiz do repositorio.

## Estrutura

```text
index.html      pagina principal
js/             logica do jogo
style/          estilos e fontes
meta/           icones para navegador/mobile
```

## Como jogar localmente

Abra `index.html` no navegador.
